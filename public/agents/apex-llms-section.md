## Agents

Agents start at https://dna.codes/agents/, the agent surface of DNA Codes. Its endpoints are served by the agent host at https://agents.dna.codes/functions/v1/dna, with bearer credentials only; this site serves none.

- [Agent llms.txt](https://dna.codes/agents/llms.txt): how an agent reads and authors DNA
- [Discovery](https://dna.codes/agents/discovery.json): the authoritative list of endpoints and versions
- [auth.md](https://dna.codes/agents/auth.md): how an agent authenticates, and the pre-claim cap
